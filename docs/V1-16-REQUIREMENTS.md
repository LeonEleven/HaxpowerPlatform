# V1-16 期初文件预览与清洗需求确认

截至 2026-11-27（Asia/Shanghai），V1-16 尚未取得正式开发指令。新 ChatGPT 会话先与项目负责人核对 B01、B03 和 B10，取得脱敏资料后确认产品模板、输入文件格式、映射和审核规则，再编写供 Codex 执行的任务书。业务决定及适用例外记入 [项目决策](DECISIONS.md)，未决事项继续记录在 [生产就绪差距](PRODUCTION-READINESS-GAPS.md#业务确认清单)。

## 需要的资料

- 旧系统库存导出 Excel 脱敏样例与产品档案导出 Excel 脱敏样例，保留列、单元格类型及异常形态。
- 不同产品分类的新建或编辑页面脱敏截图，供核实字段、必填性、可选值及多选行为。
- 仓库和库位结构，以及特殊批次、无品牌和小数数量实例。
- 旧系统员工曾把空格或空引号误认为无批次。样例需体现原始值和员工理解之间的差异。

目前资料不足以确定最终产品模板或迁移文件格式。开发和测试使用合成数据，不访问生产环境，不使用真实业务数据做实验。

## 待项目负责人确认的候选方案

### B01 产品模板与数量

- 按旧系统资料确定首批分类模板及技术属性，逐字段确认必填、多选及搜索范围。
- 考虑明确的“未知品牌”业务选项。无品牌库存禁止自动并入真实品牌 SKU 的提案待确认。
- 根据实际单位和数量样例确定单位、精度与单行数量上限。

### B03 批次规范与历史例外

- 保留原始批次值和源行，区分源数据库 NULL、空字符串、纯空白、空引号及非法值。若导出丢失原始区分，确认以何种资料复核。
- 将空引号标为疑似无批次并提交审核，可提出去掉首尾空白的候选。大小写、全半角、内部空格原则上不自动归并。
- 确认最大长度、保留前缀和历史例外。归并冲突须可追溯并审核。

### B10 校验与切换

已确认以正式切换日库存快照初始化，完整旧库存流水迁移不作为前置条件（D027）。正式期初入账始终专项签核（B06-07）；实际签核分工仍待确认。

- 候选流程是分阶段进行产品档案清洗与库存清单预览。SKU、批次或位置映射不明的记录进入人工审核。
- 切换时拟落实旧系统只读保留和历史访问安排，确认访问职责及执行方式。
- 待确认实物与系统差异处理、审核及签核人、切换窗口。统一期初记账时点及相关原生设置由 B12 确认。
