# V1-16 首批产品配置与迁移

本页细化 [B01、B03、B10 正式业务规则](DECISIONS.md#12-b01-b03-b10-正式业务规则) 中获批的首批配置和迁移流程。后续任务的授权及设计边界见 [V1-16 需求及规划](V1-16-REQUIREMENTS.md)。

## 首批属性

分类、名称、编码、单位和品牌等核心档案字段必填。以下 23 项技术属性首批均为选填且可搜索，保留按分类配置必填的能力。

| 类型 | 数量 | 属性 |
| --- | ---: | --- |
| MULTI_SELECT | 4 | 别名、件号、机型信息、刻印通用 |
| SINGLE_SELECT | 15 | 喷孔规格、冷却类型、组合数量、包装规格、排放标准、排放标记、规格类型、IMO号码、系统、造机厂、燃油品质、长度区别、结构造型、旋向、螺纹类型 |
| DECIMAL | 3 | 芯径φ(mm)、转速(rpm)、直径(mm) |
| BOOLEAN | 1 | 含油嘴 |

件号、IMO号码等标识按文本保留，Excel 处理须防止丢失前导零。喷孔规格暂作为单个属性。组合数量、喷孔规格和包装规格均为技术属性，库存数量及单位换算单独管理。旧 SKU remark 保留原文，OEM 件号和刻印的分类须有审核依据。当前未取得完整旧参数字典，首批配置仅列属性定义，历史及未来可选值由参数治理补齐。

## 迁移流程与模板范围

1. **主数据准备。** 旧系统适配层解析关系并保留原始数据及来源。标准主数据模板覆盖分类、属性、参数、模板、规格、规格属性、品牌、SKU 和历史标识。旧规格及 SKU 转为新正式编码，旧标识与来源映射长期保留。缺失、重复、冲突及不明确的记录先审核。经审核可保留缺失的历史技术属性和无库存产品。
2. **预览和盘点。** 期初盘点模板覆盖产品身份、仓库、库位、批次类型、批次号、单位、实盘数量、盘点人员及审核信息。明盘可展示旧账面参考，盲盘录入时隐藏旧账面，差异在授权核对环节查看。首次切换优先盲盘。支持盘点新增发现库存，显式区分未盘点与实盘零。旧账面负数、缺失产品或库位、仓库库位归属冲突、重复和异常状态保留为迁移证据，禁止直接写入新数量账。批次清洗依 B03 保留历史原文，人工处理异常及归并冲突。
3. **切换、签核与对账。** 提前准备主数据。正式切换前原则上处理未完成跨仓运输，无法完成的安排专项审核，禁止虚构普通库位库存。切换时冻结旧系统写入，执行实盘及审核，冻结清单。默认由不同人员准备和专项签核，明确授权的自审例外须留存授权及原因。只有审核后的实盘进入正式期初，再逐桶核对。旧系统只读保留，历史差异留证，历史库存流水留在旧系统。

具体文件字段、模板版本、审核状态机、签核例外的授权主体及实现机制由后续任务设计和评审。正式记账时点、最低估值及原生配置由 B12 在 V1-17 相关实施前确认。

## 资料与演示数据边界

业务分析依据项目负责人提供的八张旧系统数据库表 Excel、README 和界面截图。旧系统采用规格与品牌产品分离、规格级参数字典及逻辑库区。分析发现负库存、缺失产品引用、缺失库位、仓库库位归属冲突及历史状态异常。项目负责人说明历史上曾有管理员直接修改旧数据库，因此批准通过正式实物盘点重建库存账。

原始文件、实际库存数量、个人联系方式、地址和逐行真实记录限于授权环境，禁止进入仓库、测试夹具或 PR。仓库可保存获批的分类及属性名称。实际参数值及派生演示数据须符合脱敏及授权边界。文档任务仅使用获批规则和业务分析摘要。

本地演示站与自动化测试站隔离，使用接近旧系统业务规模的脱敏合成数据并支持安全重置。演示库存通过审核后的合成清单及受控原生入账路径初始化。演示数据准备可随 V1-16B/16C 推进，独立演示站、数量初始化和重置工具的工程归属由后续任务书确定。
